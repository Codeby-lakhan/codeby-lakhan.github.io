# Lakhan Singh — Portfolio

A neo-brutalist personal portfolio built with **vanilla HTML, CSS and JavaScript**. No frameworks, no build tools, no dependencies.

**[Live Site](https://codeby-lakhan.github.io)**

## What's inside

- **index.html** — the main portfolio: hero, about, skills, journey timeline, featured projects, contact
- **terminal.html** — an interactive terminal-style resume
- **neo-styles.css** — neo-brutalist styling (thick borders, hard offset shadows, bright palette, paper-tear dividers)
- **script.js** — matrix typing effect, scroll highlights, falling icons, scroll-spy nav
- **favicon.svg**, **robots.txt**, **sitemap.xml**

## Design

- Thick black borders, flat offset shadows (`box-shadow: 8px 8px 0 #000`)
- High-contrast palette: yellow, cyan, pink, green
- Paper-tear section dividers + tape stickers
- Terminals: Space Grotesk / Space Mono / Caveat

## Run locally

```
npx serve .
# or
python -m http.server 8000
```
